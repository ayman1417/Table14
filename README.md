Table14 is a modern and fully responsive recipe web application built with React and Tailwind CSS.
It allows users to explore delicious meals, search for recipes, browse by categories or areas, and save their favorite dishes in a personalized favorites page.

✨ Features
🔍 Real-time recipe search
🍲 Browse meals by categories and areas
❤️ Save and manage favorite recipes
📱 Fully responsive modern UI
⚡ Fast and optimized React application
🎨 Smooth animations and interactive design
🔐 Authentication with localStorage
🛠️ Built With
React + Vite
Tailwind CSS
HeroUI
React Router DOM
Axios
SweetAlert2
React Context API
TheMealDB API
